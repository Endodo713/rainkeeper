# RAINKEEPER

Water the valley, spare the village. An original offline canvas game about guiding a rain cloud through a thirsty valley, with procedural sound and seeded weather.

Move with the mouse, arrows, or WASD. Water seeds into sprouts and ripe crops; keep watering to harvest. SPACE spends lightning to remove nearby storms. Avoid raining on houses: three floods ends the game. Complete each day's harvest quota and finish Day 5 to win; missing a day's deadline loses the valley. P / Escape pauses, R restarts, and M mutes.

Run `node serve.ts`, then open http://localhost:8080.

Place the four captured JPEG scenes in `screenshots/`, then build with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
